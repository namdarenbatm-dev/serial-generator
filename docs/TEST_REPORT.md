## محدودیت‌های شناخته‌شده
- «Newland برای SP600» از پچ ثابت نمی‌شود؛ فقط اعلام کاربر است.
- هیستوگرام‌های فاصله در UI نمونه‌گیری‌شده‌اند (نمای تقریبی)؛ تضمین روی شاخص و تست‌هاست.
- مفسر مجموعه‌ی طلایی همان فرض‌های استخراج (عرض ۲/۳/۴ نویسه برای هر متغیر) را دارد؛ استقلال کامل از استخراج ندارد. اجرای VBA واقعی لازم است.
- Len در VBA بر پایه‌ی UTF-16 است؛ نویسه‌های خارج از BMP آزموده نشد.
- iOS Safari و دستگاه واقعی آزموده نشد (فقط شبیه‌ساز موبایل Chrome).
- Web Worker استفاده نشد؛ تولید تکه‌تکه با `setTimeout` و پیشرفت و لغو است. برای 100000 سریال رابط قفل نمی‌شود ولی سریع‌ترین مسیر نیست.
